# Project: Applying Helm Concepts to the Orderly Platform

## Overview

This project demonstrates my understanding of Helm by applying the concepts
I've learned in my Helm from Scratch learning journey to a real-world
microservices application called Orderly Platform.

Rather than relying on pre-written configurations, I am building the Helm
chart incrementally, applying my knowledge of Helm charts, templates,
values, Kubernetes resources, and application deployment.

## Project Objectives

- Apply Helm concepts to a real-world application.
- Understand how Helm charts manage Kubernetes resources.
- Learn how to configure multiple microservices using Helm.
- Practice writing and debugging Helm templates independently.
- Understand how Helm integrates with GitOps and Argo CD.

## What I Am Learning

This project will document my practical experience with:

- Helm chart structure
- Chart.yaml and values.yaml
- Helm templates
- Kubernetes Deployments and Services
- Application configuration
- Health checks and scaling
- Helm debugging and validation
- GitOps deployment with Argo CD

## Learning Approach

I will build this project incrementally, documenting the concepts,
decisions, challenges, and lessons learned at each stage.

The goal is to develop the ability to design, write, and troubleshoot
Helm charts independently.
